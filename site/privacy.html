Privacy Policy

Last updated: September 7, 2026

This Privacy Policy explains how TraceMail AI handles information when you use the TraceMail AI email security and forensic analysis application.

1. What TraceMail AI Does

TraceMail AI is an email security analysis application designed to help users investigate suspicious email messages, identify potential threat indicators, and understand security risks.

Users may analyze email evidence locally using an .EML file or connect a Gmail mailbox for read-only email security analysis.

2. Why TraceMail Requests Gmail Access

TraceMail AI requests Gmail read-only access so that it can retrieve email messages required for security analysis.

TraceMail AI uses Gmail access only for the email security functionality described in this Privacy Policy.

The Gmail permission requested by TraceMail AI is:

https://www.googleapis.com/auth/gmail.readonly

This permission is read-only. TraceMail AI does not request permission to send, modify, delete, or manage Gmail settings.

3. What TraceMail AI May Access

When a user explicitly connects a Gmail account, TraceMail AI may retrieve email information necessary for security analysis, including:

  • Email subject
  • Sender and recipient information contained in the message
  • Email timestamps
  • Email headers
  • Authentication results
  • URLs and domains contained in messages
  • IP addresses or other threat indicators contained in messages
  • Attachment metadata or hashes when required for analysis

4. What TraceMail AI Cannot Do

TraceMail AI's Gmail integration is intended to be read-only.

  • ✓ Cannot send emails
  • ✓ Cannot delete emails
  • ✓ Cannot modify emails
  • ✓ Cannot forward emails
  • ✓ Cannot change Gmail settings

5. How Email Data Is Used

Email information accessed through Gmail is used to support security analysis and investigation features, including:

  • Threat classification
  • Security indicator extraction
  • Email header analysis
  • Suspicious URL and domain identification
  • Security investigation and forensic reporting
  • User security awareness

TraceMail AI does not use Gmail data for advertising or unrelated commercial profiling.

6. Data Storage and Security

TraceMail AI is designed to keep authentication credentials and Google authorization information on the server side rather than exposing them to the browser.

Access credentials and authentication information are treated as sensitive information and should not be shared publicly, committed to source-control repositories, or exposed in client-side code.

Security principle: TraceMail AI follows a least-privilege approach and requests only the Gmail permission required for its intended read-only analysis functionality.

7. Gmail Authorization and Revocation

Gmail access is granted only after the user explicitly authorizes TraceMail AI through Google's OAuth authorization process.

You can revoke TraceMail AI's access to your Google Account at any time through your Google Account's security and connected-app controls.

Revoking authorization prevents TraceMail AI from obtaining new Gmail data through that authorization.

8. .EML File Analysis

TraceMail AI also supports analysis of individual .EML files.

This provides an alternative to connecting a mailbox and allows users to provide a specific email message as evidence for investigation.

9. Third-Party Services

TraceMail AI uses third-party services required to provide application functionality, including:

  • Google OAuth and Gmail API for user authorization and read-only Gmail access.
  • Railway for application hosting and deployment.

These services have their own privacy policies and terms. Users should review the applicable policies of those services.

10. No Silent Email Actions

TraceMail AI is designed to analyze email evidence and provide security findings.

TraceMail AI does not silently send, delete, modify, or forward user emails.

Any future response functionality involving changes to an external system should require explicit user authorization before the action is performed.

11. Changes to This Privacy Policy

This Privacy Policy may be updated when TraceMail AI's functionality, data practices, or integrations change. The updated version will be published on this page.

12. Contact

If you have questions about this Privacy Policy or how TraceMail AI handles data, please contact the TraceMail AI project team through the support contact associated with the application.
